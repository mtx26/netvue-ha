# Ancienne passerelle Python — archive

Cette archive conserve les sources, tests, configurations de déploiement et
l'ancien workflow de publication du pont Python, remplacé par la passerelle
Go à la racine du dépôt. Elle est conservée pour référence historique :
ces fichiers ne sont ni maintenus, ni exécutés, ni publiés par les workflows
actuels. Les chemins et instructions d'origine peuvent être obsolètes.

Ne déployez pas cette ancienne stack à côté du pont Go : leurs services
utilisent les mêmes ports. Les anciennes données et budgets éventuels ne sont
pas inclus dans cette archive ; ne les modifiez pas sans autorisation.

L'intégration Home Assistant Python active reste dans
[`custom_components/netvue_local/`](../../custom_components/netvue_local/).
Pour installer la version actuelle, voir le
[guide Go Portainer](../../deployment/go-portainer.md).
